## Task facts
- **Who:** AGENT (write 1 script) | **Needs:** P0-T04 (DONE) | **GPU:** none | **Time:** 30–45 min
- **Goal:** one small image (`tools/contact_sheet.py`) to review many images + video frames — the only visual-review path (CONTEXT §9).

## Implementation (`tools/contact_sheet.py`)
- argparse: `--images GLOB…`, `--videos GLOB…`, `--frames 0.1,0.5,0.9`, `--out` (default `logs/sheets/<ts>.jpg`), `--cols 4`, `--thumb 384`, `--title`.
- Tiles keep aspect (`thumbnail((thumb,thumb))`), label = filename (+ `NN%` for video), title on a top bar; sheet ≤1600 px wide (final fit-resize if needed), JPEG q80.
- Video frames: ffprobe `format=duration`, then ffmpeg `-ss <f*dur>` (before `-i`) `-frames:v 1` per fraction → temp dir, `finally: rmtree`.
- Font: truetype arial/segoe/tahoma else `load_default(size=18)`. Labels drawn as white text with a black outline (readable on any tile); `_fit_text` truncates to tile width.
- Limit: pre-count tiles (`imgs + videos*len(frames)`); if > 16 print error to stderr, **exit 2**, write nothing.
